2. Привести описание датасета.  

3. Если ваш набор данных не является аккуратным, привести его к аккуратному виду.

4. Построить графики с использованием `Altair`:
   - Построить несколько графиков разного вида.  
     > Диаграмма рассеяния, гистограмма, круговая диаграмма (см. [Vega-Altair &rarr; User Guide &rarr; Arc](https://altair-viz.github.io/user_guide/marks/arc.html)), ящик с усами, линейный график и др. *на выбор*.  

     > Добавить разные виды интерактивности в графики: подсказки, одиночные выборки, интервальные выборки, слайдеры (и др. графические элементы).

5. Построить любой график с применением слоев (базовый слой + второй слой на этой же панели аналогично примеру из лекции).

6. Построить несколько интерактивных двухпанельных (как минимум две панели, можно и больше) графиков, аналогичных примерам из лекций:
   - На первой панели реализовать возможность интерактивного выбора данных для фильтрации данных во второй панели
   - На второй панели, собственно, реализовать фильтрацию данных

7. Построить графики с применением преобразований средствами `Altair`:
  - `transform_calculate()`
  - `transform_filter()`

> Применить творческие навыки для изменения стиля отображения графиков: глобальными настройками, локальными настройками, параметрами непосредственно в самих кодировках.
